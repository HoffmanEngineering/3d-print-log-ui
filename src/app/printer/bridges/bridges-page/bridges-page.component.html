Run printlog-bridge on a NAS, home server or Raspberry Pi on your printers' network (or on a Klipper printer), and pair it with printlog-bridge pair. It shows up here after it first checks in, with the printers it found.

In Docker, give it the host's network (network_mode: host) so it can find printers. Docker Desktop can't, but you can still add printers by address.

Already paired one? It checks in once it runs a release that finds printers: update it, and it pairs again once by itself.
