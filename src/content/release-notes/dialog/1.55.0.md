**The printer catalog is here!** When you add a printer, pick it from 900+ models (or the popular ones up top) and its specs are filled in for you. Uploaded G-code even suggests which of your printers ran it. See [Printers](/docs/printers).

**New accounts get a guided start** that walks through adding a printer, the loaded spool and a first print, so if you're sharing 3D Print Log with a friend, now's a great time.
