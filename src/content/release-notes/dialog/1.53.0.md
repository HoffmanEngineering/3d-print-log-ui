**Klipper printers log every print on their own** with [printlog-bridge](/docs/printlog-bridge), a free, open source companion. Each print is logged as it happens, with how it ended, the filament each tool used and the slicer's thumbnail. The bridge also reads the slicer settings from the G-code file and adds them to the print for you, the way the Slic3r uploader does. Run it on the printer or in Docker on a NAS, where one bridge watches all of your printers, the Snapmaker U1 included. See the new [Klipper page](/klipper) to get started.

**3D Print Log can be your Spoolman server**, too. Connect a printer from its page and your spools show up in the Mainsail, Fluidd and KlipperScreen spool pickers, with nothing to install. See [Spoolman for Klipper](/docs/klipper-spoolman).
