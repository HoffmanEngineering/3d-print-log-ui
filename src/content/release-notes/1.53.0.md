title: 'Klipper Print Logging & Spoolman'
---

**Klipper printers now log every print on their own.** [printlog-bridge](/docs/printlog-bridge) is a free, open source companion that watches your printers through Moonraker and logs each print to 3D Print Log as it happens: when it starts, how it ended (completed, failed or canceled), how long it took, the filament each tool used, the slicer's thumbnail and settings, and a webcam snapshot when you have one. Run it on the printer's Raspberry Pi, or in Docker on a NAS or home server, where one bridge watches all of your printers. That includes printers you can't install software on, like the Snapmaker U1, whose RFID reader assigns Snapmaker spools to their slots automatically. Start with the new [Klipper page](/klipper).

Each printer's page now has a **Connections** section that shows what is logging it, when it last checked in, and when a newer bridge is out. Prints that an integration logged show where they came from on their details page.

**3D Print Log can be your Spoolman server.** Connect a Klipper printer from its page, paste the block into `moonraker.conf`, and your 3D Print Log spools show up in the Mainsail, Fluidd and KlipperScreen spool pickers, with nothing to install. On a printer without the bridge, the same block also logs each print and charges its filament to the spool you picked. QR labels select their spool in Fluidd's scanner, too. Free includes one Spoolman printer, and Pro connects the rest. See [Spoolman for Klipper](/docs/klipper-spoolman).

Multi-material printers get **material slots**: set how many slots a printer has, load a material into each one, and every slot's usage is logged on its own. Materials can also carry the **RFID or NFC tag UIDs** of their spools, which is how the bridge recognizes a tagged spool when it's loaded.

- **Klipper page** - A new [Klipper](/klipper) page explains automatic print logging for Klipper and how to set it up. ([PR #276](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/276))
- **Printer connections** - The printer page lists the bridges and notifiers logging that printer, with their status and when each last checked in. ([PR #262](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/262), [API PR #156](https://github.com/HoffmanEngineering/3d-print-log-api/pull/156))

- **Spoolman connections** - Connect a Klipper printer to 3D Print Log as its Spoolman server from the printer page, and manage every connection under Settings. ([PR #290](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/290), [API PR #183](https://github.com/HoffmanEngineering/3d-print-log-api/pull/183), [API PR #185](https://github.com/HoffmanEngineering/3d-print-log-api/pull/185))
- **Spoolman logs prints** - On a printer without the bridge, the Spoolman block also logs each print, with its filament charged to the spool picked on the printer. ([PR #295](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/295), [API PR #190](https://github.com/HoffmanEngineering/3d-print-log-api/pull/190))
- **Spoolman links and QR labels** - Fluidd's and Mainsail's links to a spool open that material in 3D Print Log, and QR labels select their spool in Fluidd's scanner (labels printed before this release work once reprinted). ([PR #294](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/294), [API PR #189](https://github.com/HoffmanEngineering/3d-print-log-api/pull/189))
- **Clearer Spoolman setup** - The Snapmaker U1 note gives the exact Advanced Mode steps, the button that replaces a lost block is now **Change secret**, and the setup block leaves out the notifier where it isn't needed or can't run. ([PR #328](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/328), [PR #330](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/330), [API PR #238](https://github.com/HoffmanEngineering/3d-print-log-api/pull/238))
- **Material slots** - Set a printer's number of material slots, load a material into each slot, and see usage per slot on each print. ([PR #264](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/264), [API PR #158](https://github.com/HoffmanEngineering/3d-print-log-api/pull/158))
- **RFID and NFC tags on materials** - Add a spool's tag UIDs to its material, with a clear message when a tag is already on another material. ([PR #267](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/267), [PR #278](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/278), [API PR #159](https://github.com/HoffmanEngineering/3d-print-log-api/pull/159))
- **Safer print edits** - Saving a print sends only the fields you changed, so a form left open while a print was running can't undo what the printer reported since. ([PR #266](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/266))
- **Terms of service** - New [Terms of Service](/docs/terms-of-service), and the privacy policy now covers what data is collected, why, who receives it, how long it's kept and your choices. ([PR #261](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/261))

- **Fixed links between docs pages** - Links to a section of another documentation page open that section instead of "Page not found". ([PR #327](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/327))
