title: 'Print Form, Sign-In & Spool Fixes'
---

This release is a round of fixes from a close look at the print form, the lists and sign-in. The biggest one: if a print saved but its photos failed to upload, saving again no longer creates a second copy of the print and takes the material off your spools twice. The print keeps what already went up and retries only the photos.

Saving a printer is now safer too. The printer page sends its loaded spools only when you changed them on the page, so renaming a printer or adding a photo no longer undoes a spool change that a print, the bridge or another tab made while the page was open.

Sign-in recovers on its own when a saved session has expired or been revoked: you are taken to sign in once and brought back to the page you were on, instead of being left on a page where nothing loads. After an update, a page that fails to load its newest files reloads once by itself.

#### Full List of Changes:

- **Duplicate prints after a failed photo upload** - When a new print saved but its photos did not, the form now says "Your print was saved, but its photos were not. Save again to retry them." Saving again updates that print and uploads only the photos that are missing. ([PR #435](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/435))
- **Images that cannot be read** - An image your browser cannot open (such as a TIFF, or a HEIC in Chrome) shows an error instead of leaving Save spinning forever. ([PR #435](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/435))
- **Completion date and time** - Changing Actual Print Time or Start Date updates the completion date and time on the form, and editing Completion Time no longer clears Actual Print Time. ([PR #435](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/435))
- **Remembered settings on the print form** - "Remember Allow Comments" is applied to new prints, and copying a print uses your default measurement type again. ([PR #435](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/435))
- **Changing the printer on a print** - The material rows no longer keep spools from the printer you switched away from. ([PR #435](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/435))
- **Editing a print that failed to load** - Shows a message and returns to the print instead of opening a blank form that would create a new print. ([PR #435](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/435))
- **New print without a printer** - If you have no printers yet, the form now asks you to add the printer you printed on, and Save points you to the **Add printer** button instead of showing an error about a hidden field. Anything you already entered is kept. ([PR #446](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/446))
- **Clearing a print's project** - The x button that clears the project on the print form no longer saves the print and leaves the page. ([PR #443](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/443))
- **Loaded spools on the printer page** - Saving a printer leaves its loaded spools alone unless you changed them on the page. ([PR #439](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/439), [API PR #330](https://github.com/HoffmanEngineering/3d-print-log-api/pull/330))
- **Project images** - Projects follow the same image limit as prints: 5 on Free and 20 on Pro. You can pick several images at once, swap an image on a project that is at its limit in one edit, and saving again after a failed upload does not repeat the uploads that worked. ([PR #437](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/437), [API PR #326](https://github.com/HoffmanEngineering/3d-print-log-api/pull/326))
- **Comments that could not be posted** - If a comment is refused or fails to send, your text stays in the box and a message says why. The button is disabled while it posts, so a double click posts once. ([PR #438](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/438))
- **Slicer file notes** - OrcaSlicer, Bambu Studio and Anycubic files report supports correctly (they could say "No Supports" when supports were on, and the reverse). PrusaSlicer's draft shield setting is read from newer files, including a new "Draft Shield: Limited" note. Cura files saved with Windows line endings get their notes again. ([PR #436](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/436))
- **Bambu Studio material usage** - Bambu Studio files now fill in the filament length and weight. ([PR #436](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/436))
- **Print list** - Deleting the only print on the last page goes back to the last page with prints instead of showing an empty table. Back and Forward restore the list that matches the filters shown. A bookmarked filter on a deleted material no longer stops the list from opening. ([PR #436](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/436))
- **Printer list and public profiles** - Searching, filtering or switching profiles starts again from the first page, so real matches are no longer hidden behind "Nothing matched" or "No Prints Found". Clearing the search on a public profile shows every print again. ([PR #440](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/440))
- **API keys** - Deleting an API key asks you to confirm first. Creating a key makes one key even on a double click, and a new key's secret no longer disappears if the list was slow to load. ([PR #440](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/440))
- **Mark as Empty** - Uses the spool's latest remaining amount, so a spool used since the list loaded cannot go below zero. ([PR #440](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/440))
- **Project source links** - A link typed without `https://` now opens the site instead of a "page not found" in 3D Print Log. ([PR #440](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/440))
- **Names in confirmation dialogs** - A name containing `<` shows in full. ([PR #440](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/440))
- **G-code viewer and QR labels** - The G-code viewer listens only to its own window, and QR labels check the material's temperature and color before printing them. ([PR #440](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/440), [PR #436](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/436))
- **Sign-in recovery** - An expired or revoked session sends you to sign in once and back to the same page. A sign-in link opened twice, or finished in another tab, goes to the home page instead of a spinner that never ends. ([PR #431](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/431))
- **Pages after an update** - If a page cannot load because the site was just updated, it reloads once by itself. ([PR #431](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/431))
- **Notifications check less often** - The notification bell checks for new notifications every minute while the tab is open and visible, pauses in background tabs and while offline, and refreshes as soon as you come back. ([PR #429](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/429))
- **Smaller fixes** - Checking Done on a maintenance entry you have not saved yet no longer fails, changing a setting twice quickly no longer saves it twice, a custom analytics date range in the future no longer fails to load, and a profile link with a bad id goes to the "user not found" page instead of breaking. ([PR #429](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/429))
- **Ads** - Ads load only where they fit on the screen, once per page, and Pro members no longer see one appear briefly before their account loads. ([PR #430](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/430))
