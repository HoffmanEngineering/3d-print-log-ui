**Project start and finish dates** are here! Every project now shows when it started and when it wrapped up, based on the prints it contains, and you can pin either date by hand from the project edit form when the prints do not tell the whole story. This one came in as a user suggestion, so thank you for sending it in!

The **home page** and the **documentation** have both been redesigned. Docs pages now have search, a contents rail that follows you as you scroll, and screenshots captured from the real app. Every old documentation link still works.
