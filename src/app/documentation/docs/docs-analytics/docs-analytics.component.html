Analytics

Navigate to the Analytics section to view statistics about your 3D prints.

Analytics Overview

Analytics shows you information in a specific date range. Use the Select Date Range dropdown to choose a specific range.

Prints By Status Panel

The Prints By Status panel groups the prints by their Print Status: Pending/Printing/Success/Failed/Cancelled. It shows the total number of prints in the selected Date Range in the center, with an arc representing the group for each individual status.

Click the View Legend slider to toggle the legend, which shows each print status and the total number of prints with that status in the date range.

Total Print Time Panel

The Total Print Time Panel shows the sum of print times for all prints in the selected Date Range. It will use the Actual Print Time if recorded, otherwise it will use the print's Estimated Print Time.

Total Filament Used Panel

The Total Filament Used Panel shows the sum of filament usage for all prints in the selected Date Range. It will use the print's Actual Filament Used if recorded, otherwise it will use the print's Estimated Filament Used.
