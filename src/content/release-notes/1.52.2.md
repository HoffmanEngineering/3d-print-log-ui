title: 'Contact Page, API Docs & Under-the-Hood Fixes'
---

A new [Contact](/docs/contact) page explains how to reach us, and a new [REST API & Authentication](/docs/api) page covers how to call the 3D Print Log API and sign in with an API key.

Most of this release is behind the scenes. 3D Print Log now runs on the latest Angular patch release, a large internal refactor brings the app in line with current Angular patterns, and AI assistants and search engines can now find the documentation and the MCP server more easily.

#### Full List of Changes:

- **Contact page** - A new [Contact](/docs/contact) page, with links to it and to the other trust pages from the footer and documentation. ([PR #232](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/232))
- **REST API documentation** - A new [REST API & Authentication](/docs/api) page covers the API and how to authenticate. ([PR #219](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/219))
- **Settings on phones** - The filament display unit toggles in [Settings](/settings) now stack on narrow screens instead of running off the edge. ([PR #239](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/239))
- **Documentation loads faster** - Documentation pages are now fully prerendered, so their content appears before the app finishes loading. ([PR #238](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/238))
- **Real "not found" pages** - Unknown addresses now return a proper 404 page instead of an empty app. ([PR #218](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/218))
- **Documentation as Markdown** - Every documentation page is also published as Markdown for AI assistants and other tools. ([PR #229](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/229))
- **Discovery for AI agents** - The site now publishes standard discovery files for the API, the MCP server, the docs MCP endpoint and an agent skill. ([PR #220](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/220), [PR #234](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/234), [PR #235](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/235), [PR #236](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/236))
- **Search engine improvements** - Richer structured data for search results ([PR #231](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/231)), and the sitemap now tells search engines when pages and public prints last changed ([PR #233](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/233)).
- **Reliability fixes** - Fixed background subscriptions in Settings and print comments that were not cleaned up when you left the page. ([PR #240](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/240))
- **Dependency updates** - Angular 21.2.25 and security fixes for third-party packages, including a safer duration parser. ([PR #242](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/242), [PR #243](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/243))
- **Modernized internals** - Components now use Angular's signal inputs, outputs and queries, host metadata and built-in template control flow. ([PR #241](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/241), [PR #244](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/244), [PR #245](https://github.com/HoffmanEngineering/3d-print-log-ui/pull/245))
