Getting Started

3D Print Log is a tool for tracking 3D prints and filaments, accessible from any internet-connect device.

Features:

  • Record every print in a searchable history
  • Save print settings for each print
  • Keep track of printing status
  • Record estimated vs actual print times
  • Manage your roll of filaments and track filament usage

Quickstart Guide:

  1. Create a free account
  2. Create your first Printer
  3. Add your Filament Rolls/Spools on the Filament Page
  4. Add your first Print
