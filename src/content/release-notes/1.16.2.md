The **3D Print Log Uploader Plugin for Cura** has been updated to version 2.0.2. This version adds support for the new Cura 5 Beta, as well as adding in new settings to control the "Would you like to send to 3D Print Log" prompt.

You can install v2.0.2 of the plugin via the [Ultimaker Cura Marketplace](https://marketplace.ultimaker.com/app/cura/plugins/3d-print-log/3dPrintLogUploader) . Alternatively, you can download the [Latest Release from Github](https://github.com/ChristopherHoffman/3d-print-log-cura-plugin/releases) and drag/drop into Cura to install.
