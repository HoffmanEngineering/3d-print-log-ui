title: 'Filter Materials by Storage Location'
---

This release adds a **Filter by Storage Location** dropdown to the
[Materials](/materials) page, making it easy to view all filaments in a specific
storage box or shelf at a glance. Pair it with the **Print Labels** button to
quickly print QR labels for everything in a given storage location.

#### Full List of Changes:

- **Filter by Storage Location** - A new single-select dropdown in the Materials filter panel lets you filter your filament list by storage location. Choose a named location, select _Unassigned_ to see filaments with no storage location set, or leave it at _No Filter_ to see everything.
