title: 'OctoPrint Integration'
---

3D Print Log now has an OctoPrint Integration! 3D Print Log can receive information from Octoprint in order to create and update print statuses, print time, and filament usage. It will also save pictures from the camera on success/failure. Visit the [3D Print Log OctoPrint Webhook Docs](/docs/octoprint-webhook) for information on how to set up the integration.
